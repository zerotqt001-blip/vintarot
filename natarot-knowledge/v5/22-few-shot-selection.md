# Few-Shot Selection v5

Golden readings are style/quality references, not authoritative answers.

Selection score:
1. same language
2. same domain
3. same spread shape / similar position semantics
4. similar interpretive challenge (reversal, contradiction, feelings-vs-actions, ambiguity)
5. partial card overlap only as a weak bonus

Use zero examples for simple requests, one for normal readings, at most two for difficult readings.
Never select examples merely because the same final card appears.
Never copy sentences from examples into the live reading.
If examples conflict with authoritative drawn-card knowledge or position semantics, ignore the example.
