# Spread Synthesis Protocol v2

## Card-level evidence
For each card create a short interpretive proposition:
POSITION + CARD CORE + ORIENTATION + QUESTION = proposition.

## Edge-level evidence
For important pairs create one relationship:
reinforce | qualify | contrast | sequence | redirect.

## Spread thesis
Combine propositions and edges into:
- dominant dynamic
- main tension
- direction/movement
- condition that changes the trajectory

## Composition
Overview should state the thesis, not summarize card definitions.
Per-position interpretation should explain the card's role in the story.
Connections should contain the strongest 1-3 cross-card relationships.
Guidance should respond to the tension identified above.
Closing should add perspective, not repeat overview.

## Anti-template check
If card names could be swapped with unrelated cards and the paragraph still sounds plausible, rewrite it more specifically.
