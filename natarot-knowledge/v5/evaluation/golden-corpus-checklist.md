# Golden Corpus Review Checklist

Before promoting an example to production few-shot:
- all card names/orientations match input
- every position is respected
- overview contains a real thesis
- at least one meaningful cross-card connection
- no unsupported factual mind-reading
- no deterministic future
- no medical/legal/financial certainty
- reversed meaning is not mechanically inverted
- guidance derives from spread
- closing does not duplicate overview
- language sounds native
- no reusable mystical filler

Production recommendation: manually review and approve examples used as few-shot anchors.
