# Provider A/B Test

Run identical inputs through OpenAI, Gemini, and DeepSeek with temperature/config as comparable as possible.

Blind the provider names. Score with quality-rubric.md.

Track:
- total score /50
- fail conditions
- latency
- input/output tokens
- cost
- JSON/schema failure rate
- repetition rate across similar readings

Use at least 30 cases before choosing production default. Include VI and EN, 1/3/5+ cards, mixed reversals, love/career/decision, and contradictory spreads.
